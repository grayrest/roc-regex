# M2 — Unicode Tier A

Real Unicode ranges, generated from `regex-syntax` 0.8 via its public parser
(`tools/uni/`), packed as 6-hex-digit codepoint pairs in `Str` literals with a
decoder that folds them to `List({lo,hi})` at compile time (D4). Generated into
`package/Uni.roc`.

## Coverage

- **`\w \d \s` (and `\W \D \S`)** now use the real Unicode sets — `\d` matches
  Arabic-Indic digits, `\w` matches Unicode letters, verified.
- **`\p{Name}` / `\P{Name}`** for a Tier-A subset: `L Lu Ll N Nd P Sm Zs` general
  categories and `Greek Latin Cyrillic Han` scripts, plus `Letter`/`Number`/
  `Punctuation` aliases.
- **`(?i)`** as a leading flag: the AST's `Chars` nodes are case-folded via the
  simple-fold orbit table (BMP through U+1FFF), so `(?i)σ` matches `Σ`.
- **Unicode `\b`** uses the Unicode `\w` set (a range scan per boundary; M3's DFA
  does it via classes).

## Differential result

`tools/diff` extended with Unicode and `(?i)` patterns over Greek, Cyrillic,
Arabic-digit, accented-Latin and mixed-case haystacks: **1431/1431 agree with the
Rust regex crate.** Zero divergences.

## Gate — Unicode artifact cost

Three Unicode patterns (`\w+@\w+`, `\p{L}+\d*`, `(?i)error|warn|info`) folded via
a runtime `pick` so the artifacts embed:

| measure | value |
|---|---|
| fold wall time (3 patterns, cold) | 10.9 s |
| peak RSS | ~358 MB (~215 MB above baseline) |
| artifact delta | 462,768 B (**~154 KB/pattern**) |

Inside SR2 (500 MB). The ~154 KB/pattern is dominated by `\p{L}`'s per-pattern
trie (thousands of atoms, many leaf blocks) — this is exactly the per-pattern
cost D3's open fork flags, and it is the concrete M2 measurement that motivates
the shared codepoint→atom trie. `(?i)`-folded and `\w`-only patterns are far
smaller.

When both pattern and haystack are literals the **entire match folds to a
constant** and nothing embeds — confirmed (a `\p{L}+` match on a literal haystack
built to a 390,528 B baseline binary).

## Scope not yet covered (honest)

Full `\p{}` (all gc values, all scripts, age/break properties); `(?i:...)` scoped
groups and `(?i)` mid-pattern; `\p{}` inside `[...]`; the shared-vs-per-pattern
trie decision (D3 fork). The generator (`tools/uni`) extends to more properties
by adding to its class list.
