# SIMD Teddy prefilter — Roc's SIMD is sufficient after all

The earlier claim (D6, M4 note, the plan's "The shape") that Roc has no
user-facing SIMD was **wrong**. Roc exposes portable 128-bit vector intrinsics
(`U8x16`…`U64x2`) lowering to x86-64 / AArch64 NEON / wasm, and they cover
Teddy's hot loop exactly.

## Primitives → Teddy steps (all verified to build and run)

| Teddy step | Roc primitive | lowers to |
|---|---|---|
| load 16 haystack bytes | `U8x16.load` | `movdqu` / `ldr q` / `v128.load` |
| nibble split | `bitwise_and(splat 0x0F)`, `shr_zf_wrap(4)` | — |
| nibble → bucket-mask lookup | `table_lookup` | `pshufb` / `tbl` / `i8x16.swizzle` |
| consecutive-byte alignment | `concat_shift_bytes(a, b, n)` | `palignr` / `ext` / `i8x16.shuffle` |
| candidate lane extraction | `eq_lanes` + `bitwise_not` + `to_bitmask` | `pcmpeqb` + `pmovmskb` |

The `shift_in_one_byte(res, prev)` of aho-corasick's Teddy is
`prev.concat_shift_bytes(res, 15)` here; `shift_in_two_bytes` is `…, 14`. A
candidate lane `j` in window `w` maps to a match start of `w + j - (M-1)`.

## `package/Teddy.roc`

Basic ("Slim") 128-bit Teddy: ≤8 literals, one bucket bit each, an M-byte
fingerprint with M = min(3, shortest literal). `build` makes the M nibble-table
pairs; `candidates` scans 16-byte windows carrying the previous window's
fingerprint results (for the cross-window `concat_shift_bytes`), plus an overlap
window and a scalar tail for haystacks under 16 bytes. It returns an ascending
**superset** of literal-start offsets; the engine verifies each by anchored
`match_at`.

## Validation

- **304/304** superset (no false negatives) over 8 literal sets × 38 haystacks
  spanning lengths 3–80 — every 16-byte-window seam, and empty/absent cases.
- Wired into `find` via `Comp.lead_literals` (an alternation of ≥2 literal-
  prefixed arms → the literal set; `tlits` on `Regex.T`). `foo|bar|baz`,
  `cat|dog|cow|pig`, `foo.*|bar.*` all take the Teddy path and match Rust;
  `[abc]|xy` correctly falls through (an arm has no literal prefix).
- Full 1431-case differential still **1431/1431** vs the Rust crate; smoke 21/21.

Teddy is built at match time from the stored `tlits` (six 16-byte tables — cheap)
rather than folding `U8x16` constants into the artifact.

## Scope

Basic 128-bit Teddy only. AVX2 "fat" Teddy (256-bit, more buckets) needs
`U8x32`, which Roc does not expose — genuinely deferred. Verification is scalar
`memcmp` via the engine, so no Aho-Corasick automaton is needed (D6 stands).
