# M1 gate measurement

Taken 2026-09-02 on the M1 engine (parser + NFA + PikeVM + class trie), macOS
arm64, `roc build --no-cache`, basic-cli 0.21.0. This is the gate the plan's M1
section defines: fold time, peak compiler RSS, and artifact bytes **including the
class trie**, for realistic patterns, plus the bad-literal build-failure test.

## Correctness

`examples/smoke.roc`: **21/21**, including a non-ASCII range (`[α-ω]+` matched
through the two-level trie's leaf path) and `\b`, anchors, lazy quantifiers,
alternation, `{n,m}`, and negated classes. This is M1's ~15-case bar, exceeded.

## Fold cost — three named production-shaped patterns

Folded at top level, indexed at runtime (the D9 folded-program form, since
`expect` does not fold):

- `\d{4}-\d{2}-\d{2}. \d{2}:\d{2}:\d{2} \w+ \w+` (timestamp + level + logger)
- `\w+=\w+` (key=value)
- `(\w+.)+\w+` (dotted identifier)

| measure | value |
|---|---|
| baseline empty app binary | 390,528 B |
| gate binary (3 folded patterns + tries) | 458,576 B |
| **artifact delta** | **68,048 B (~22.7 KB/pattern)** |
| baseline peak RSS | ~144 MB |
| fold peak RSS | ~187 MB (**~43 MB above baseline**) |
| fold wall time (cold, 3 patterns) | 1.65 s |

Artifact bytes here are whole-binary delta, which folds the flat NFA, the split
table, and the trie (ascii + l1 + leaves + accept bitsets) together — the
per-object breakdown S2 calls for is not yet split out and is owed before SR1's
threshold is set from this.

## Against the thresholds

- **SR2 (peak RSS < 500 MB above baseline):** ~43 MB. Passes with an order of
  magnitude of headroom.
- **`max_artifact_bytes` provisional 256 KB:** ~23 KB/pattern. Passes.
- **Abandonment (p90 artifact < 1 MB/pattern):** ~23 KB. Nowhere near. The fold
  survives at this scale — unverified item 1 is, for M1-sized patterns,
  discharged.

## D7 headline feature

A bad literal pattern fails the build with the rendered caret message. Measured
verbatim from `roc build` on `Regex.unwrap(Regex.compile("(foo|bar"))`:

```
    regex: unclosed group
      | (foo|bar
      | ^
```

## Not yet measured

The per-object artifact split (trie vs NFA vs tables); the shared-vs-per-pattern
trie comparison (D3 fork, M2); and patterns large enough to exercise the
256-distinct-block ceiling S2 notes. SR1's threshold stays unset until the
per-object split and the M1.5 corpus exist.
